Obtén esta URL en Google Apps Script → Implementar → Administrar implementaciones → copiar URL de la aplicación web.

Pasos para configurar: 1. Abre script.google.com → Nuevo proyecto
2. Pega el contenido de Code.gs que descargaste
3. Cambia SHEET_ID por el ID de tu Google Sheet
4. Implementar → Nueva implementación → Tipo: Aplicación web
5. Ejecutar como: Yo · Acceso: Cualquier persona
6. Autorizar y copiar la URL aquí
